# Mahalaxmi Textiles - Luxury Fabric Manufacturer & B2B Showcase

A luxury digital storefront, B2B wholesale platform, and interactive fabric catalog for **Mahalaxmi Textiles**.

---

## 🌟 Key Features

- **Luxury Modern Aesthetic**: Custom glassmorphism design system in obsidian and royal gold typography.
- **Interactive Fabric Catalog**: Filter by Pure Cotton, Liva Rayon, Foil & Khari Print, Vintage Discharge Print, Digital Print Modal, and Vat Mill-Dyed solids with real-time search.
- **Technical Specification Modal**: Inspect GSM, fabric weave, composition, shrinkage rates, and colorway swatches.
- **Live B2B Pricing Calculator**: Dynamic meter slider (500m - 20,000m), finish treatments (Bio-washed, Silicone drape, Mercerized, Water-repellent), volume tier discounts, and instant WhatsApp RFQ generation.
- **Mill Infrastructure & Certifications**: OEKO-TEX® Standard 100, GOTS Certified, ISO 9001:2015, and Sedex SMETA audited.
- **Sample Swatch Request Form**: Direct RFQ and physical swatch book dispatch form with toast notifications.

## 🚀 Quick Start

1. Clone or download the repository:
   ```bash
   git clone https://github.com/chakrashen/mahalaxmi_fiber.git
   cd mahalaxmi_fiber
   ```
2. Open `index.html` directly in your browser or run a local static server:
   ```bash
   python -m http.server 8080
   ```
3. Visit `http://localhost:8080` in your browser.
